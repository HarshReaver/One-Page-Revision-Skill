# Logistic Regression - Revision Sheet

## Key ideas
- Supervised ML algorithm for classification, not regression; predicts probability an input belongs to a class
- Sigmoid maps linear model values to 0-1, forming an "S" shaped curve
- MSE gives a non-convex cost, hard to find minima, so use log loss instead
- Log loss gives a convex curve: guarantees a global minimum
- Training like Linear Regression with Gradient Descent: initialize parameters, predict, compute gradients, update, repeat until convergence
- Types: Binomial, Multinomial, Ordinal
- Assumptions: independent observations; binary dependent variable; linear relationship between predictors and log odds; no extreme outliers; large sample size

## Key formulas
- `g(z) = 1/(1+e^-z)` - sigmoid, range (0,1); g(z)→1 as z→∞, →0 as z→−∞, =0.5 at z=0
- `hθ(x) = 1/(1+e^-θᵀx)` - probability of class 1; z = θ0+θ1x1 = θᵀx
- `J(θ) = -(1/m) Σ[y·log(ŷ) + (1−y)·log(1−ŷ)]` - log loss; m = samples, y = actual, ŷ = predicted
- Loss per sample: `-log(ŷ)` for y=1; `-log(1−ŷ)` for y=0
- `∂J/∂θ1 = (1/m)(ŷ−y)x` and `∂J/∂θ0 = (1/m)(ŷ−y)`
- `∂ŷ/∂z = ŷ(1−ŷ)` - used in the chain rule

## Must-know definitions
- **Logistic Regression**: supervised ML algorithm for classification problems (not regression ones)
- **Sigmoid function**: maps linear model values to the range 0 to 1
- **Log Loss (Binary Cross Entropy)**: cost function used instead of MSE; penalizes severe wrong predictions
- **Binomial**: output has only two categories (Yes/No, Pass/Fail, 0/1)
- **Multinomial**: 3 or more categories, not ordered (cat, dog, rabbit)
- **Ordinal**: 3 or more categories with natural order (low, medium, high)

## Common mistakes / exam traps
- Linear Regression predicts continuous values; Logistic Regression is for classification
- Using MSE J(θ) of linear regression gives a non-convex function
- Severe wrong predictions cost a lot: y=0 & ŷ=0.9 → very high loss; y=0 & ŷ=0.1 → low loss
- Multinomial (unordered) vs Ordinal (ordered): don't mix up
- For more than two categories SoftMax functions are used
- Extreme outliers distort the coefficient estimates

## Self-check (answer without looking)
1. What does hθ(x) represent?
2. What is g(z) at z=0, and its limits as z→±∞?
3. Why not use MSE as the cost function?
4. Which type fits "low/medium/high" ratings?
5. y=0 and ŷ=0.9: is the loss high or low, and which loss term applies?

## Answers
1. Probability of the input belonging to class 1. 2. 0.5; →1 as z→∞, →0 as z→−∞. 3. Non-convex, hard to find minima. 4. Ordinal. 5. Very high; −log(1−ŷ).
