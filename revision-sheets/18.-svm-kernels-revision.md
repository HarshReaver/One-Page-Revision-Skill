# SVM Kernels - Revision Sheet

## Key ideas
- SVMs use kernels to handle non-linear relationships by implicitly mapping data into higher-dimensional spaces
- Choosing the right kernel can have a big impact on performance
- Four common kernels: Linear, Polynomial, RBF (Gaussian), Sigmoid
- Linear: fast, memory-efficient; cannot capture complex non-linear patterns
- Polynomial and RBF: more flexible, but both can overfit
- RBF works well for many real-world problems
- Sigmoid is often worse than RBF

## Key formulas
None in this chapter.

## Must-know definitions
- **Kernel**: lets SVMs handle non-linear relationships by implicitly mapping data into higher-dimensional spaces
- **Linear Kernel**: pros - fast, memory-efficient, less risk of overfitting, works well with many features
- **Polynomial Kernel**: pros - can model interactions between features, more flexible than linear
- **RBF (Gaussian) Kernel**: pros - very flexible, works well for many real-world problems
- **Sigmoid Kernel**: pros - can mimic neural network decision boundaries

## Common mistakes / exam traps
- Linear kernel: cannot capture complex, non-linear patterns
- Polynomial: higher degrees can overfit; computationally more expensive
- RBF: sensitive to hyperparameters; overfits if γ is too large
- Sigmoid: not always a valid kernel for all parameters; often performs worse than RBF
- Picking a kernel carelessly: the right kernel has a big impact on performance
