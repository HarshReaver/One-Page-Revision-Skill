# KNN - K Nearest Neighbors - Revision Sheet

## Key ideas
- Supervised ML algorithm for classification and regression
- Predicts by looking at the K closest data points to a new point; "Tell me who your neighbors are, and I'll tell you who you are"
- Steps: choose odd K (3, 5, 7, 9...); measure distance to all existing points; find K nearest (least distance); predict
- Classification: majority vote of the K neighbors (that's why K is odd)
- Regression: average of the K neighbors' values
- Lazy learner: stores the entire dataset, computes only at classification time
- Feature scaling is required for better performance

## Key formulas
- Euclidean: `d = √((x2−x1)² + (y2−y1)²)` - shortest distance between P1(x1, y1) and P2(x2, y2); most common
- Manhattan: `d = |x2−x1| + |y2−y1|` - grid-like travel, only horizontal and vertical moves

## Must-know definitions
- **KNN (K-Nearest Neighbors)**: supervised ML algorithm used for classification and regression
- **K**: number of nearest neighbors used for the prediction; chosen as an odd number
- **Euclidean Distance**: shortest distance between two points
- **Manhattan Distance**: distance travelled in a grid-like city, moving only horizontally and vertically
- **Lazy learner**: does not learn from the training set immediately; stores the entire dataset and computes only at classification time

## Common mistakes / exam traps
- Skipping feature scaling: a feature ranging -999 to 999 gets higher weightage in Euclidean distance than one ranging 0 to 1
- Mixing up the prediction rules: classification = majority vote, regression = average
- Choosing an even K (K should be odd)
- Mixing up Euclidean (straight-line) and Manhattan (horizontal + vertical only)
- Thinking KNN learns a model upfront; it only computes at prediction time
